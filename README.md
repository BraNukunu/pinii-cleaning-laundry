# Pinii Cleaning & Laundry

Premium corporate website built with Next.js, React and Tailwind CSS for Winneba and Ghana's Central Region.

## Run

Install dependencies with `npm ci`, run locally with `npm run dev`, and verify a production build with `npm run build`.

## Quote requests

The booking form validates required fields and prepares a WhatsApp message to +233548818011. Visitors review and send it in WhatsApp. No booking is confirmed automatically; Pinii agrees price, availability and access directly. The website does not store customer submissions or send background requests.

## Content

Business details supplied by the owner: Winneba base, Central Region service area, 0548818011 contact, and 24/7 service availability. No invented reviews, ratings, prices, certifications, or customer counts are included. Gallery and hero photographs are AI-generated illustrations, visibly labelled on the website. Replace with authorised real photos when available.

## Deployment

Deploy to Vercel using the Next.js preset. No environment variables or external database are required. Keep the repository connected to Vercel to deploy future commits automatically.
